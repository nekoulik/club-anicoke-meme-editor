# 🎮 Club Anicoke — Редактор мемов

Веб-редактор мемов и постов для аниме-клуба [Club Anicoke](https://vk.ru/anicoke).
Чистый HTML/CSS/JS — без сборки, без сервера, без зависимостей.
Открой страницу — и твори.

> 🔗 **Попробовать онлайн:** [nekoulik.github.io/club-anicoke-meme-editor](https://nekoulik.github.io/club-anicoke-meme-editor/)

## ✨ Возможности

- 🖼️ 6 лейаутов (1–6 секций) + загрузка своих фото с фильтрами (6 пресетов + ручные настройки)
- 🎭 9 стикеров-персонажей: поворот, отражение, размер колесом мыши
- 📝 Текст: шрифт группы, градиентная заливка, неоновое свечение, обводка, тень
- 💬 Облачка реплик с 5 направлениями хвостика
- ➡️ Фигуры: стрелка, прямоугольник, звезда, круг, линия
- 🔗 Группировка слоёв (Ctrl+G) и поиск по слоям
- 🧲 Snap-направляющие при перетаскивании (Shift — отключить)
- 🏷️ Ватермарка группы (встроенный логотип или свой PNG)
- 📐 Форматы: аватар 800×800, обложка RUTUBE 2204×864 (с безопасной зоной 📱),
  YouTube 1280×720, лента 800×1000, сторис 720×1280
- 📦 Массовый экспорт — 5 форматов одной кнопкой
- 💾 Автосохранение в localStorage + история 30 шагов (Ctrl+Z / Ctrl+Y)
- 📋 Шаблоны постов (анонс, опрос) и кнопка «🎲 Случайный мем»

## 🚀 Запуск

**Локально:** открой `index.html` в браузере
(или `python -m http.server` → http://localhost:8000).

**GitHub Pages:** Settings → Pages → Branch: `main` → Save.
Через минуту редактор доступен по ссылке:
[nekoulik.github.io/club-anicoke-meme-editor](https://nekoulik.github.io/club-anicoke-meme-editor/)

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |
| `Ctrl+D` | Дублировать слой |
| `Ctrl+G` / `Ctrl+Shift+G` | Сгруппировать / разгруппировать |
| `Delete` | Удалить слой |
| `Стрелки` / `Shift+стрелки` | Сдвиг на 1px / 10px |
| `Shift` (при перетаскивании) | Отключить snap |
| Колесо мыши на слое | Размер слоя |
| Двойной клик по облачку | Изменить реплику |

## 🛠️ Стек

- **HTML5** — разметка
- **CSS3** — стили (grid, backdrop-filter, CSS-переменные)
- **Vanilla JS** — логика без фреймворков
- **Canvas API** — отрисовка и экспорт
- **localStorage** — автосохранение

Никаких сборщиков (Vite/Webpack), никаких npm-пакетов. Всё работает из коробки.
